Linguagens de Desenvolvimento Web

Front-end

O Front-end é a parte visual e interativa de um site ou aplicação web com a qual o usuário interage diretamente. As linguagens e tecnologias front-end são responsáveis pela estrutura, estilo e comportamento da interface do usuário no navegador.

HTML CSS JavaScript React Angular

Back-end

O Back-end é a parte "por trás dos panos" de um site ou aplicação web. Ele lida com a lógica do servidor, banco de dados, autenticação, processamento de dados e outras funcionalidades que não são diretamente visíveis para o usuário. As linguagens back-end são executadas no servidor.

Python JavaScript (Node.js) Java PHP Ruby
